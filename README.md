# Dragon Particle Collider NFT

Proyecto interactivo de NFT con animaciones GSAP.

## Descripción
Dragón interactivo con efectos de partículas y animaciones GSAP.

## Tecnologías
- HTML5/CSS3
- JavaScript
- GSAP Animation
- Web3.js
- MetaMask Integration
